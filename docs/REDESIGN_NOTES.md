# 기존 디자인 보존형 재설계 기록

## 1. 재설계 목표

`ui-mockup-main`의 레일, 상단바, 3단 편집기, 패널 밀도와 청록색 브랜드 체계를 기준 디자인으로 유지했다. 화면을 새 제품처럼 교체하지 않고 전략 편집기의 사용성 문제만 해결했다.

1. Basic 사용자는 Scratch처럼 모양을 맞추는 과정에서 순서와 데이터 흐름을 자연스럽게 이해한다.
2. Pro 사용자는 노드를 자유롭게 배치하면서도 잘못된 타입·시간축·실행 방향은 즉시 구분한다.
3. 입력 중에는 필수값 누락을 막지 않고 완료 단계의 구조 검사에서 해결한다.
4. 종목과 전략 수치를 추천하지 않고 사용자가 직접 입력한다.

## 2. 유지한 시각 구조

- 왼쪽 72px 전역 메뉴 레일
- 상단 브랜드·알림·사용자 영역
- 전략 상단 툴바와 시작점 카드
- 왼쪽 라이브러리, 중앙 편집기, 오른쪽 전략 확인 패널
- 흰색 표면, 가는 경계선, 낮은 그림자, 절제된 청록색
- 카테고리 색상과 작은 영문 Eyebrow
- 봇·방 화면의 기존 마스터–상세 구조

## 3. Basic 편집기

- 블록은 `유니버스 → 데이터 → 지표 → 신호 → 포트폴리오 → 위험 → 주문 → 기록` 순서의 접두형 퍼즐로 결합한다.
- 다음 순서의 블록만 활성 강조하고 다른 블록은 순서 잠금으로 표시한다.
- 블록을 클릭하거나 끌어놓을 수 있지만 맞지 않는 순서는 결합하지 않는다.
- 중간 블록을 분리하면 뒤쪽 블록도 함께 보관함으로 돌아가 잘못된 실행 순서를 만들지 않는다.
- 블록 위의 홈과 아래의 돌출부는 전달 타입별 모양을 사용한다.
- 카테고리는 색으로, 데이터 타입은 모양과 텍스트로 구분한다.
- 종목, 시간축, 계산 방식, 기간, 기준값, 비중, 위험 한도, 주문 방식과 기록 범위를 블록 안에서 직접 입력한다.
- 필수값은 입력 중 차단하지 않고 오른쪽에서 문제·영향·해결 방식으로 안내한다.
- 구조 결과는 성과 그래프가 아니라 연결 순서와 백테스트 준비 상태만 보여준다.

## 4. Pro 편집기

- `@xyflow/react` 좌표형 캔버스에서 노드를 자유롭게 이동한다.
- 입력·출력마다 개별 Handle ID를 사용해 다중 포트 노드를 정확히 연결한다.
- 14종 데이터 타입에 서로 다른 포트 모양을 적용한다.
- 타입, 시간축, 관찰 전용 여부, 실행 단계, 순환과 입력 중복을 연결 시 검사한다.
- 호환되지 않는 포트는 연결하지 않고 `문제 → 영향 → 해결` 문장을 표시한다.
- 연결 중에는 같은 타입·시간축·방향의 후보 포트만 밝아진다.
- 자주 쓰는 핵심 입력 1~2개는 노드 안에, 전체 입력은 오른쪽 설정 탭에 둔다.
- 노드 내부와 오른쪽 패널의 입력은 같은 상태를 사용해 즉시 동기화된다.
- 노드 선택 시 설정, 입력·출력, 검증 탭을 제공한다.
- 설명은 상시 노출하지 않고 제목의 물음표에 호버하거나 키보드 초점을 둘 때만 표시한다.
- 노드 복제, 비활성화, 삭제, 자동 정렬, 실행 취소와 다시 실행을 제공한다.
- Shift 다중 선택으로 그룹을 만들고 그룹 이동·접기·펼치기·해제를 제공한다.
- 선택 노드나 그룹은 본인 계정 전용 블루프린트로 저장하며 공유·내보내기는 제공하지 않는다.

## 5. 추가한 전략 도구

- 블록 검색과 카테고리 필터
- 데이터 능력이 없는 블록의 잠금과 잠금 사유
- 오류·경고·정보 심각도를 구분한 전략 린터
- 선택 노드가 없을 때 전략 요약과 접근성용 실행 순서 목록
- 접이식 하단 패널의 시장 차트, 신호 미리보기, 간편 검증, 데이터 품질 탭
- 실제 데이터 연결 전에는 임의의 가격·수익률·신호를 만들지 않는 빈 미리보기
- Pro 편집기 오류가 발생해도 빈 화면 대신 복구 안내를 보여주는 오류 경계

## 6. 법적·제품 안전 원칙

- 특정 종목, 종목 조합, 매매 방향, 기간, 비중, 임계값과 주문 가격을 추천하지 않는다.
- 튜토리얼은 UI 조작만 설명하고 전략 수치나 성과를 제안하지 않는다.
- 셀렉트의 구조 선택값 외에 투자 판단 수치는 비워 두고 사용자가 직접 입력한다.
- 특정 종목이 포함된 전략 템플릿을 기본 노출하지 않는다.
- 구조 검사, 백테스트와 라이브 모의 결과를 전략 인증·안전성·수익 보장으로 표현하지 않는다.
- 실제 출시 전 금융 규제, 투자 권유·자문 해당 여부와 문구에 대해 전문 법률 검토가 필요하다.

## 7. 검증 기록

- TypeScript 정적 검사와 Vite 배포 빌드 통과
- Basic 순서 결합, 직접 입력, 서로 다른 포트 형태 확인
- Pro 기본 스타일 import와 미니맵 위치 확인
- Pro 노드 드래그 전후 좌표 변경 확인
- VolumeSeries → PriceSeries 연결 차단과 안내 문구 확인
- 노드 입력과 오른쪽 설정 동기화, 오류 수 감소 확인
- 물음표 설명의 기본 숨김과 초점 표시 확인
- 입력·출력 탭의 타입·시간축·필수 여부 확인
- 접이식 데이터 품질 패널 확인
- 자동 정렬과 실행 취소·다시 실행 확인
- Shift 다중 선택, 그룹 생성·접기 확인
- 그룹을 본인 계정 전용 블루프린트로 저장하는 흐름 확인

## 8. 샘플 한계

- 상태는 브라우저 메모리에만 유지한다.
- 실제 인증, 계정 저장소, 실시간 시세, 백테스트 엔진과 주문 API에 연결되지 않는다.
- 데이터 능력 상태는 데모 정의이며 실제 최신성·결측 검사는 서버가 담당해야 한다.
- 모바일에서는 읽기 전용 안내가 필요하며 편집은 데스크톱을 기준으로 한다.
