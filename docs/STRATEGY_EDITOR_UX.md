## 2. 공통 시각 언어

색은 블록 역할만 나타내고 연결 호환성을 의미하지 않는다.

| 카테고리 | 색상 | 역할 |

| 시장 데이터 | `#0369A1` | 가격·거래량 입력 |

연결 타입은 모양, 텍스트 레이블과 시간축을 함께 사용한다. 모든 연결부는 `14×14`의 1:1 외곽 영역을 사용하며, 비슷한 의미의 타입은 같은 기본 도형을 공유한다. 세부 타입은 이중 외곽선, 내부 점, 선, 막대와 확인 표시로 구분한다.

|---|---|---|---|
| 대상 · 원형 | `Asset` | 원 | `port-shape--asset` |

| 데이터 · 정사각형 | `VolumeSeries` | 내부 막대 정사각형 | `port-shape--volumeseries` |
| 수치 · 마름모 | `Scalar` | 마름모 | `port-shape--scalar` |
| 수치 · 마름모 | `Metric` | 이중 마름모 | `port-shape--metric` |

| 신호 · 삼각형 | `EventTrigger` | 내부 점 삼각형 | `port-shape--eventtrigger` |

| 주문·상태 · 육각형 | `ApprovedOrder` | 내부 확인 육각형 | `port-shape--approvedorder` |
| 주문·상태 · 육각형 | `PositionState` | 내부 선 육각형 | `port-shape--positionstate` |

라이브러리, Basic 퍼즐, Pro 캔버스는 모두 `PortSwatch` 공통 컴포넌트로 실제 도형을 렌더링한다. Pro의 React Flow `Handle`은 연결 판정 영역만 담당하고 그 안에 같은 `PortSwatch`를 표시한다. 따라서 화면별 CSS 크기 재정의 때문에 모양이 달라지지 않는다.

라이브러리의 `연결부 모양 안내`를 펼치면 다섯 도형군과 전체 타입을 확인할 수 있다. 개별 연결부에 마우스를 올리면 정확한 타입, 세부 모양, 시간축과 관찰 전용 여부를 확인한다.

## 3. Basic 결합 규칙

1. 현재 연결된 블록 수로 다음 필수 순서를 계산한다.
2. 다음 블록만 `다음` 상태로 강조한다.
3. 다른 블록을 놓으면 추가하지 않고 필요한 타입과 선행 블록을 설명한다.
4. 블록 입력 홈과 이전 블록 출력 돌출부의 타입 모양이 같아야 한다.
5. 중간 블록을 제거하면 그 뒤쪽도 함께 제거해 역순·고립 상태를 만들지 않는다.
6. 필수 입력 누락은 편집 중 허용하고 완료 버튼만 비활성화한다.
7. 완료 검사에는 남은 블록, 필수값과 위험 제한의 우선 적용 정보를 포함한다.

## 4. Pro 연결 규칙

연결 시 다음 순서로 검사한다.

1. 실제 전략 노드끼리 연결했는가
2. 자기 자신으로 연결하지 않았는가
3. 비활성·잠금 노드가 아닌가
4. 시작·도착 Handle ID가 유효한가
5. 포트 타입이 같은가
6. 타입에 시간축이 있으면 시간축도 같은가
7. 관찰 전용 출력이 실행 입력으로 향하지 않는가
8. 실행 단계가 역방향이 아닌가
9. 새 연결이 순환을 만들지 않는가
10. 도착 입력이 이미 다른 연결로 채워지지 않았는가

실패하면 연결선을 저장하지 않고 다음 형식으로 안내한다.

`문제: 무엇이 맞지 않는가 → 영향: 왜 실행할 수 없는가 → 해결: 사용자가 무엇을 확인할 수 있는가`

해결 문구는 특정 종목이나 투자 수치를 제안하지 않는다.

## 5. 노드 정보 구조

- 노드 카드: 카테고리, 이름, 한 줄 역할, 핵심 입력 1~2개, 상태 배지
- 오른쪽 설정 탭: 전체 입력
- 입력·출력 탭: 포트 모양, 타입, 시간축, 필수·선택·관찰 여부
- 검증 탭: 선택 노드와 관련된 오류·경고·정보
- 물음표 툴팁: 설명, 수식, 필요 데이터 능력, 비추천 안내
- 빠른 행동: 복제, 비활성화·활성화, 삭제

설명 툴팁은 기본적으로 숨기고 `:hover`, `:focus`, `:focus-within`에서만 표시한다.

## 6. 전략 검사 심각도

| 단계 | 동작 |
|---|---|
| 오류 | 봇 생성 완료 단계 차단 |
| 경고 | 사용자가 확인한 뒤 진행 가능 |
| 정보 | 실제 적용 순서나 동작 설명 |

현재 검사 항목은 필수 파라미터, 필수 입력, 타입·시간축, 데이터 능력, 비활성 연결, 워밍업, 목표 비중·현금 충돌과 위험 제한 우선 적용이다.

## 7. 보조 도구

- 실행 취소·다시 실행: 최근 40개 구조 스냅샷
- 자동 정렬: 실행 단계별 가로 열, 같은 단계별 세로 행
- 그룹: Shift 다중 선택, 함께 이동, 접기·펼치기, 해제
- 접힌 그룹 연결: 그룹 안팎을 잇는 실제 연결은 유지하고, 화면에서는 그룹 테두리의 대표 포트로 연결선을 이어 표시
- 그룹 대표 포트: 입·출력 방향과 타입·시간축별로 분리하고, 같은 종류의 연결 수 배지와 내부 연결 목록 툴팁 제공
- 개인 블루프린트: 선택 노드나 그룹을 본인 계정에서만 재사용
- 빠른 삭제: 선택 후 `Delete`·`Backspace`, 또는 노드 드래그 중에만 나타나는 캔버스 중앙 하단 삭제 박스 사용
- 드롭 삭제: 삭제 박스 안에 놓으면 대기 없이 즉시 삭제하고, 박스 밖에 놓으면 일반 노드 이동으로 처리
- 삭제 복구: 삭제 직후 알림의 `실행 취소`로 노드와 연결을 함께 복원
- 화면 이동: 노드를 캔버스 가장자리로 끌면 자동 이동하며, 삭제 박스보다 아래의 하단 가장자리는 아래쪽 화면 이동 전용으로 유지
- 레이어 정리: 삭제 박스는 중앙 하단에만 표시하고, 선택 작업은 캔버스 위 부유 레이어 대신 상단 도구 모음에 표시
- 접힌 그룹 크기: 펼친 그룹 폭과 별도로 최대 폭을 제한하고, 제목·동작 버튼과 대표 포트 행을 분리
- 하단 패널: 시장 차트, 신호 미리보기, 간편 검증, 데이터 품질
- 접근성 순서 목록: 그래프를 읽기 어려운 사용자를 위한 선형 실행 순서
- 오류 경계: Pro 편집기 오류 시 빈 화면 대신 복구 안내

## 8. 비추천·데이터 정책

- 종목, 종목 조합, 방향, 기간, 임계값, 비중과 주문 가격을 추천하지 않는다.
- 특정 종목이 채워진 템플릿이나 성과·인기·추천 배지를 제공하지 않는다.
- 투자 판단 수치는 빈 상태로 두고 사용자가 직접 입력한다.
- 선택형 구조 값은 기능 옵션일 뿐 투자 권장값으로 표현하지 않는다.
- 실제 데이터가 없을 때 가격, 성과와 매매 신호를 임의 생성하지 않는다.
- 잠긴 데이터 블록은 제거하지 않고 필요한 데이터 능력과 잠금 사유를 표시한다.
- 구조 검사 통과는 수익성·안전성·전략 적합성 인증이 아니다.

## 9. 튜토리얼 완료 상태

- Basic과 Pro의 완료 상태를 각각 저장한다.
- 마지막 단계의 `완료`와 `전체 건너뛰기`를 모두 해당 모드 확인 완료로 처리한다.
- 확인 완료한 모드는 전략 화면에 다시 들어와도 자동 실행하지 않는다.
- 아직 확인하지 않은 다른 모드로 처음 전환하면 해당 모드 튜토리얼을 시작한다.
- 상단 `튜토리얼`, 도움말의 빠른 시작, 설정의 `Basic 다시 보기`와 `Pro 다시 보기`로 명시적으로 재실행할 수 있다.
- 완료 상태는 현재 실행형 샘플의 브라우저 로컬 저장소에 보관한다.

### 9.1 실제 편집기를 사용하는 연습 세션

- 튜토리얼은 설명용 가짜 화면이 아니라 실제 Basic·Pro 편집기에서 진행한다.
- 시작 시 현재 전략의 블록·노드·연결을 메모리에 백업하고 비어 있는 연습 공간을 연다.
- 연습 중 변경은 자동 저장하지 않아 기존 전략의 브라우저 저장본을 덮어쓰지 않는다.
- 기존 전략이 있었다면 `완료`와 `전체 건너뛰기` 모두 튜토리얼 시작 전 상태를 자동 복원한다.
- 기존 전략이 비어 있었다면 종료 시 `빈 편집기로 돌아가기`와 `연습 내용 유지`를 사용자가 선택한다.
- `구성 시작`에서 의도적으로 초기화한 경우에는 초기화 전 전략을 연습 종료 후 되살리지 않고 빈 전략을 기준으로 처리한다.

### 9.2 Basic 5단계 실습

1. `원하는 종목 선택하기` 블록을 첫 홈에 직접 드래그한다.
2. 서비스 추천 없이 회사명 또는 심볼을 사용자가 직접 입력한다.
3. `가격 데이터 불러오기` 블록을 다음 홈에 드래그해 Universe 퍼즐 연결을 만든다.
4. 가격 데이터 시간축을 사용자가 직접 선택한다.
5. 완료 후 기존 전략 복원 또는 빈 전략의 연습 내용 유지 여부를 처리한다.

### 9.3 Pro 5단계 실습

1. `직접 선택 바스켓` 노드를 캔버스에 직접 드래그한다.
2. `가격·거래량` 노드를 원하는 위치에 직접 드래그한다.
3. 두 노드의 Universe 출력·입력 포트를 선으로 연결한다.
4. 선택된 `가격·거래량` 노드에서 시간축과 최대 지연을 사용자가 직접 입력한다.
5. 완료 후 기존 그래프를 자동 복원하거나 빈 전략의 연습 내용 유지 여부를 처리한다.

### 9.4 투자 권유 방지

- 튜토리얼은 종목, 시간축, 최대 지연, 기간, 임계값과 비중의 예시값이나 권장값을 제시하지 않는다.
- Pro 연습용 `가격·거래량` 노드의 시간축과 최대 지연은 빈 상태로 시작한다.
- 완료 문구는 편집 조작을 익혔다는 의미만 전달하며 투자 적합성, 안전성 또는 수익성을 암시하지 않는다.

## 11. 브라우저 검증 항목

- Basic 첫 두 블록을 순서대로 추가하고 내부 입력 동작 확인
- Basic 라이브러리와 배치 블록의 `Universe`가 모두 `14×14` 이중 원인지 확인
- Pro 8개 초기 노드와 14개 Handle 렌더링 확인
- Pro 라이브러리와 캔버스의 원형·정사각형·마름모·삼각형·육각형 CSS가 일치하는지 확인
- 노드 드래그 전후 좌표 변화 확인
- `VolumeSeries → PriceSeries` 연결 시 엣지 수가 증가하지 않는지 확인
- 연결 실패 문구에 문제·영향·해결이 포함되는지 확인
- 오른쪽 입력 변경이 노드 내부 입력과 동기화되는지 확인
- 입력 후 오류 수가 감소하는지 확인
- 물음표 설명이 기본 숨김이고 초점 시 표시되는지 확인
- 그룹 생성·접기와 계정 전용 블루프린트 저장 확인
- 그룹 내부 노드와 외부 노드 연결 후 그룹을 접어 대표 포트와 연결선이 유지되는지 확인
- 같은 방향·타입·시간축의 외부 연결이 대표 포트 하나와 개수 배지로 합쳐지는지 확인
- 대표 포트에 마우스를 올려 내부 노드와 외부 노드 연결 목록을 확인
- `Delete`·`Backspace` 삭제 후 알림의 실행 취소로 노드와 연결이 복원되는지 확인
- 노드를 캔버스 가장자리로 끌 때 화면이 이동하고 삭제되지 않는지 확인
- 노드를 중앙 하단 삭제 박스에 빠르게 놓아도 즉시 삭제되고 실행 취소로 복원되는지 확인
- 삭제 박스보다 아래로 노드를 끌면 삭제되지 않고 그래프 화면이 아래쪽으로 이동하는지 확인
- 자동 정렬·실행 취소·다시 실행 확인
- 하단 데이터 품질 패널 펼침 확인

- 아직 확인하지 않은 Basic 모드로 처음 전환할 때 Basic 튜토리얼만 시작하는지 확인
- 설정에서 현재 모드 튜토리얼을 다시 시작할 수 있는지 확인
- Basic에서 종목 블록 배치, 직접 입력, 가격 블록 결합, 시간축 선택 순서로 5단계가 진행되는지 확인
- Basic 가격 블록을 다음 홈에 놓을 때 드롭 이벤트가 중복 처리되지 않고 블록이 정확히 2개만 남는지 확인
