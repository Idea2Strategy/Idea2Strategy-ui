# 상호작용 혼란 UX 점검

## 목적

버튼처럼 보이지만 반응하지 않거나, 상태 표시가 이동·실행 요소처럼 보이거나, 입력한 값이 결과에 반영되지 않는 문제를 점검했다. 이번 점검의 기준은 다음과 같다.

1. 클릭 가능한 요소는 클릭 뒤 눈에 보이는 상태 변화나 결과를 제공한다.
2. 클릭할 수 없는 상태·정책 표시는 버튼과 다른 색, 커서, 아이콘을 사용한다.
3. 화살표는 실제 이동이나 펼침 동작이 있을 때만 사용한다.
4. 필터는 선택 상태와 목록 결과가 함께 바뀌어야 한다.
5. 입력 누락은 편집 중 즉시 막지 않고 완료 동작에서 한 번에 안내한다.
6. 데모에서 저장되지 않는 정보는 실제 저장처럼 오해시키지 않는다.

## 점검 및 수정 결과

| 번호 | 화면 | 혼란 요소 | 수정 결과 |
|---:|---|---|---|
| 1 | 전략 상단 | `종목 직접 선택`, `수치 직접 입력`이 버튼처럼 보임 | 회색 정책 칩으로 바꾸고 `정책 ·` 접두어와 설명 툴팁을 추가했다. |
| 2 | 전략 진행 단계 | `구성 시작`이 무반응 | 수평 스텝퍼의 완료 단계 점을 누르면 Basic/Pro 편집 내용을 빈 상태로 초기화하고 튜토리얼 1단계를 연다. |
| 3 | 전략 진행 단계 | 현재 편집 방식 카드가 버튼인데 무반응 | 박스형 카드를 제거하고 연결선 위의 강조 점으로 현재 `전략 편집` 단계를 표시한다. |
| 4 | 전략 진행 단계 | `구조 검사`가 무반응 | 스텝퍼의 다음 단계 점을 누르면 현재 모드의 구조 검사를 실행하고 첫 오류·경고와 해결 방법을 토스트로 표시한다. |
| 5 | 전략 상단 | 전략 이름과 아래 화살표가 무반응 | 연필 아이콘으로 바꾸고 이름 변경 모달과 저장 동작을 연결했다. |
| 6 | Pro 전략 | 빈 그래프 검사가 정보 메시지만 표시 | `전략 그래프가 비어 있습니다`를 완료 불가 오류로 표시한다. |
| 7 | 알림 | 정보 카드 끝 화살표가 이동을 암시 | 상세 이동 기능이 없으므로 화살표를 제거했다. |
| 8 | 도움말 | 튜토리얼·용어집·주문 상태 버튼이 무반응 | 튜토리얼 재시작, 용어집 본문, 주문 상태 설명 화면을 각각 연결했다. |
| 9 | 봇 | 상단 `조치 필요` 카드가 무반응 | 문제가 있는 봇을 선택하고 `확인` 필터와 개요 탭을 연다. |
| 10 | 봇 | 상태 필터가 무반응 | 전체·실행·정지·확인 필터가 실제 목록을 변경하고 선택 상태를 표시한다. |
| 11 | 봇 | `원인 상세`이 무반응 | 문제 원인, 안전 안내, 활동 기록 이동을 포함한 모달을 연다. |
| 12 | 방 | 전체·모집 중·공식 방 필터가 무반응 | 검색어와 필터 조건을 함께 적용해 목록을 갱신한다. |
| 13 | 방 | 방 저장 아이콘이 의미 불명확하고 무반응 | 북마크 아이콘, 툴팁, 눌림 상태와 저장/해제 동작을 추가했다. |
| 14 | 방 | `참여 중인 방 열기`, `방 관리`가 무반응 | 참여 방 요약과 운영 상태 변경 모달을 각각 연결했다. |
| 15 | 방 만들기 | 일정·제출 수 입력이 생성 결과에 반영되지 않음 | 모든 필드를 상태와 연결하고 생성된 방 기간에 대회 일정을 반영한다. |
| 16 | 방 만들기 | 이름만 입력하면 생성되어 체크리스트와 결과가 불일치 | 버튼은 계속 누를 수 있게 두고 완료 시 누락·날짜 순서·제출 수를 한 번에 검사한다. |
| 17 | 설정 | 시간대와 모션 설정을 바꿔도 화면에 반영되지 않음 | 시간대 표기와 모션 감소 클래스에 즉시 반영한다. 버튼 명칭은 `설정 저장` 대신 `완료`로 바꿨다. |

## 의도적으로 클릭 동작이 없는 요소

- Pro 노드의 물음표는 마우스 올림과 키보드 초점으로 설명을 여는 보조 정보 트리거다. 매번 설명 창이 열리지 않도록 별도 클릭 동작을 두지 않았다.
- `현재 화면`, 자동 저장 상태, 법적 정책 칩, 봇 집계 수치는 정보 표시다. 버튼 태그와 손가락 커서를 사용하지 않는다.
- 알림 카드는 현재 샘플에서 상세 페이지가 없으므로 이동 화살표를 표시하지 않는다.

## 검증 결과

- TypeScript 검사와 Vite 배포 빌드를 통과했다.
- Basic에서 블록 추가 후 `처음부터 직접 구성`을 누르면 블록이 1개에서 0개로 초기화되고 튜토리얼이 열린다.
- Basic 구조 검사에서 첫 미완료 항목과 해결 방법이 표시된다.
- Pro에서 초기 노드 8개를 빈 그래프로 초기화할 수 있고, 검사 시 빈 그래프 오류가 표시된다.
- 전략 이름 변경 결과가 상단에 즉시 반영된다.
- 도움말 용어집이 열리고 본문을 확인할 수 있다.
- 봇 `확인` 필터는 문제 봇 1개만 표시하고 원인 상세 모달을 연다.
- 방 `공식 방` 필터는 공식 방 1개만 표시한다.
- 빈 방 생성 폼에서 완료 버튼을 누르면 누락 항목 안내가 표시된다.
- 시간대를 ET로 변경하면 상단 시간대가 `ET · KST 병기`로 바뀐다.
- 브라우저 콘솔 오류는 발견되지 않았다.

## 데모 한계

- 로그인은 실제 인증이 아닌 데모 진입 기능이다.
- 변경 내용은 브라우저 메모리에만 유지되며 새로고침하면 초기화된다.
- 봇, 주문, 백테스트, 방 데이터는 실제 서버와 연결되지 않은 샘플 데이터다.
- 특정 종목, 전략 수치, 주문 가격은 추천하지 않으며 사용자가 직접 입력한다.
