# Phase 5 대회 방 UI/UX 구현 기록

## 1. 목표

대회 방은 참가자의 전략을 공개하거나 특정 전략을 추천하는 공간이 아니다. 모든 참가자에게 같은 모의 운용 기준을 적용하고, 사용자가 직접 선택한 성과 지표로 결과를 비교하는 공간으로 설계한다.

## 2. 정보 구조

방 상세 화면은 한 화면에 모든 정보를 나열하지 않고 네 영역으로 나눈다.

1. `안내`: 대회 기간, 참가자, 제출 한도, 공통 비교 기준과 내 제출 상태
2. `성과 비교`: 여섯 가지 모의 성과 지표와 사용자 선택 정렬
3. `참가 현황` 또는 `제출 관리`: 참가자의 제출 완료·대기·잠금·철회 상태
4. `운영 이력`: 모집, 일정, 참가 상태와 종료 변경 기록

## 3. 참가자 흐름

### 3.1 제출 가능 조건

- 방 상태가 `모집 중`이어야 한다.
- 봇에 해결되지 않은 운영 문제가 없어야 한다.
- 운영을 영구 종료한 봇이 아니어야 한다.
- 선택한 전략 버전에 완료된 백테스트가 있어야 한다.

조건을 충족하지 못한 봇은 선택 목록에서 숨기지 않는다. 선택 불가 상태와 구체적인 이유를 함께 표시해 사용자가 다음 행동을 이해하도록 한다.

### 3.2 제출과 교체

- 사용자는 제출할 봇과 완료된 백테스트가 있는 전략 버전을 함께 선택한다.
- 제출 전에 시작 자본, 종목 범위, 체결 방식과 비용 기준을 다시 확인한다.
- 모집 중에는 참여 철회와 봇 교체가 가능하다.
- 대회 시작 후에는 봇과 전략 버전이 잠기며 변경 버튼 대신 잠금 이유를 표시한다.

## 4. 전략 비공개 원칙

`전략 공개 여부`는 설정 항목으로 제공하지 않는다. 다음 항목은 항상 비공개다.

- 전략 구조와 블록·그래프 구성
- 사용자가 선택한 종목
- 포지션과 주문 기록
- 개인 블루프린트와 전략 보고서

성과 비교 화면에는 참가자 별칭, 봇 별칭, 전략 버전 표기와 모의 성과 지표만 표시한다. 운영자도 전략 내부를 열람할 수 없다는 점을 방 생성과 제출 관리 화면에서 반복 확인한다.

## 5. 성과 비교

다음 여섯 지표를 같은 표에서 비교한다.

- 누적 수익률
- 최대 낙폭(MDD)
- 변동성
- 샤프지수
- 승률
- 거래 횟수

서비스가 하나의 지표를 최종 순위로 추천하지 않는다. 사용자가 정렬 지표와 `큰 값부터` 또는 `작은 값부터`를 직접 선택한다. 선택한 지표 열은 형태와 배경으로 강조하고, 내 봇 행에는 `내 봇` 표기와 테두리를 함께 사용한다.

모든 성과 값에는 `모의 성과`와 실제 결과를 보장하지 않는다는 설명을 표시한다.

## 6. 운영자 흐름

### 6.1 참가 상태

운영자는 참가자를 `제출 완료`, `변경 잠금`, `제출 대기`, `철회`로 구분해 확인한다. 참가자 제출을 철회 처리할 때는 성과 비교에서 제외된다는 영향을 확인한 뒤 실행한다.

### 6.2 모집과 일정

- 모집 중단은 기존 제출을 유지하고 새 제출과 봇 교체만 중단한다.
- 모집 중단 전에 영향을 받는 제출 수를 표시한다.
- 일정 변경 전에 잠금 시점과 현재 제출 건에 미치는 영향을 표시한다.
- 대회 종료는 별도 확인을 거쳐 성과 집계를 멈추고 제출을 잠근다.

모든 변경은 시간, 실행자, 변경 내용과 영향 설명을 운영 이력에 남긴다.

### 6.3 공식 방과 개인 방

- 공식 방은 공식 운영자만 공통 기준과 전체 공지를 관리하며 감사 이력을 유지한다.
- 개인 방 운영자는 모집, 일정, 참가 제출과 종료를 관리한다.
- 개인 방에는 공식 배지나 공식 운영 권한을 부여하지 않는다.

## 7. 방 생성

방 생성은 작성 도중 입력을 차단하지 않는다. 마지막 생성 단계에서 다음 항목을 한 번에 검증한다.

- 방 이름
- 모집 시작·종료와 대회 시작·종료
- 사용자당 제출 봇 수
- 시작 가상자금
- 허용 종목 범위
- 비교 벤치마크
- 모의 체결 기준
- 비용 기준

방 생성 화면에서는 특정 종목, 수치, 임계값을 추천하지 않고 운영자가 공통 기준을 직접 작성하도록 한다.

## 8. 샘플 데이터와 보관

현재 실행형 샘플의 방, 제출, 성과와 운영 이력은 브라우저의 로컬 저장소에 보관한다. 화면에 표시되는 성과는 UI 동작 확인을 위한 모의 데이터이며 실제 투자 결과가 아니다.
