# I2S UI/UX 개선 샘플 · 기존 디자인 보존판

> **상태:** 이 저장소는 제품 방향을 탐색하기 위한 참고용 UI 프로토타입입니다. 현재 UX, 문구, 화면 구조와 코드 아키텍처는 확정 사양이 아니며 이후 크게 변경되거나 전면 교체될 수 있습니다.

`ui-mockup-main`의 레일, 상단바, 3단 편집기, 패널 밀도, 색상과 봇 마스터–상세 구조를 유지하면서 인터뷰에서 확정한 UX 원칙만 추가한 별도 샘플입니다.

## 실행

현재 컴퓨터에서는 프로젝트 폴더에서 다음 명령만 실행하면 됩니다.

```powershell
.\start.cmd
```

브라우저에서 `http://localhost:5173`을 엽니다. 서버를 종료하려면 실행한 터미널에서 `Ctrl+C`를 누릅니다.

Node.js와 pnpm이 시스템에 설치된 일반 개발 환경에서는 다음 명령을 사용합니다.

```bash
pnpm install
pnpm dev
```

기본 주소는 `http://localhost:5173`입니다. 배포용 결과물은 `pnpm build`로 생성합니다.

## 반영한 핵심 흐름

- 데모 로그인과 문제 발생 봇 우선 홈 화면
- Basic의 Scratch 퍼즐형 블록 끌어놓기·강제 순서 결합·블록 내부 직접 입력
- Pro의 자유 노드 배치·14종 타입 포트·시간축 검사·다중 선택
- Pro 노드 그룹화·그룹 이동·접기·펼치기·해제
- 계정 안에서만 저장·재사용하는 개인 블루프린트
- 노드 내부 핵심값과 오른쪽 전체 설정의 실시간 동기화
- 물음표 호버·초점 설명, 입력·출력 탭, 오류·경고·정보 린터
- 실행 취소·다시 실행·자동 정렬·접이식 4탭 미리보기
- 봇의 일시정지·중단·재개·운영 종료
- 사용자가 직접 기간과 비용을 정하는 백테스트
- 방 탐색·참여·생성·관리
- 알림·도움말·설정 보조 기능

## 법적·안전 원칙

- 특정 종목, 매매 방향, 기간, 비중, 임계값, 주문 가격을 추천하지 않습니다.
- 사용자가 종목과 모든 전략 수치를 직접 입력합니다.
- 구조 완성이나 백테스트 결과를 수익성·안전성의 인증으로 표현하지 않습니다.
- 보고서 공유·내보내기와 블루프린트 공유 기능을 제공하지 않습니다.
- 실제 서비스 출시 전 금융 규제와 투자 권유 해당 여부에 대한 전문 법률 검토가 필요합니다.

## 검증 결과

- 2026-07-19 기준 TypeScript 검사와 Vite 배포 빌드가 통과했습니다.
- Basic 강제 순서 결합, 직접 입력, Universe·PriceSeries 포트 형태를 확인했습니다.
- Pro 노드 자유 드래그로 실제 좌표가 변경되고 8종 이상의 포트 모양이 동시에 구분되는 것을 확인했습니다.
- VolumeSeries를 PriceSeries에 놓았을 때 연결 수가 유지되고 문제·영향·해결 안내가 표시되는 것을 확인했습니다.
- 노드 입력과 오른쪽 설정이 동기화되고 입력 완료 시 오류 수가 감소하는 것을 확인했습니다.
- 물음표 설명이 평소에는 숨겨지고 호버·초점에서만 나타나는 것을 확인했습니다.
- Shift 다중 선택, 그룹 생성·접기, 계정 전용 블루프린트 저장을 확인했습니다.
- 자동 정렬, 실행 취소, 하단 데이터 품질 패널을 확인했습니다.
- 봇 중단 안내, 방 탐색, 페이지 전환 시 스크롤 초기화를 확인했습니다.
- 브라우저 콘솔 오류는 발견되지 않았습니다.

세부 설계 및 검증 내용은 `docs/REDESIGN_NOTES.md`와 `docs/STRATEGY_EDITOR_UX.md`에 정리했습니다.

버튼처럼 보이지만 동작하지 않는 요소, 상태와 행동의 구분, 필터·설정·완료 단계 검증에 대한 재점검 결과는 `docs/INTERACTION_UX_AUDIT.md`에서 확인할 수 있습니다.

메인 페이지와 방 페이지의 정보 계층을 개선할 때 참고한 웹 디자인 시스템과 적용 근거는 `docs/REFERENCE_BASED_READABILITY_REDESIGN.md`에 정리했습니다.

## 샘플 한계

- 모든 데이터는 브라우저 메모리의 데모 데이터입니다.
- 실제 인증, 서버 저장, 시세 데이터, 주문 API와 연결되지 않습니다.
- 페이지를 새로 고치면 사용 중 변경한 데모 상태가 초기화됩니다.
